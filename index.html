Fiche express

Docker expliqué simplement

Une fiche pour retenir les idées importantes, même quand on débute complètement.

📦→🚀

1. Docker, c’est quoi ?

Imagine une boîte qui contient une application et tout ce dont elle a besoin. Cette boîte peut fonctionner sur plusieurs ordinateurs de la même façon.

Image = le modèle 📦
Conteneur = la boîte en train de fonctionner 🚀
💻↔🔲

2. Le port, c’est une porte

Un conteneur est isolé. Pour ouvrir une porte vers ton navigateur, on publie un port.

docker run -p 8080:80 httpd

La porte 8080 de ton ordinateur mène à la porte 80 du conteneur.

🗂️↔🐳

3. Le volume garde les fichiers

Sans volume, les fichiers écrits dans le conteneur disparaissent quand il est supprimé. Un volume relie ton dossier au conteneur.

docker run -v /app:/site httpd

À gauche : ton ordinateur. À droite : le conteneur.

📄→🏗️

4. Le Dockerfile est la recette

On écrit les étapes dans un fichier. Docker suit la recette pour fabriquer une image.

FROM nginx:alpine
COPY index.html /usr/share/nginx/html

FROM choisit la base. COPY met un fichier dans l’image.

👀+🛠️

5. Les commandes réflexes

docker psvoir les conteneurs

docker logs weblire leurs messages

docker exec -it web shentrer dedans

docker stop webarrêter

🌐+⚙️+🗄️

6. Compose rassemble la stack

Une application complète peut avoir plusieurs conteneurs. Compose les décrit tous dans un seul fichier, comme une fiche qui dit quoi démarrer.

🌐 web⚙️ api🗄️ db
services:
  web:
    image: nginx:alpine
  api:
    build: ./api
  db:
    image: postgres:16-alpine
docker compose up -d« démarre web + api + db »

services = la liste des conteneurs. image utilise une image existante ; build fabrique l'image depuis un Dockerfile.

👀 Observer

docker logs -f websuivre les messages

docker exec -it web shentrer dans un conteneur

docker compose psvoir l'état de la stack

🧹 Arrêter et nettoyer

docker stop webarrêter

docker rm websupprimer le conteneur

docker system prunenettoyer les éléments inutilisés

🏗️ Construire et publier

docker build -t mon-api:1.0 .fabriquer une image

docker loginse connecter au Hub

docker push monlogin/mon-api:1.0publier une image

🧩 Compose

docker compose up -ddémarrer la stack

docker compose logs -f apisuivre les logs de l'API

docker compose downarrêter la stack

⚠️ Attention : docker compose down -v supprime aussi les volumes nommés et leurs données.
